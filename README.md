# Minecraft Bedrock Cheat Scanner

Kotlin + Jetpack Compose (Material3) sample app — scanner для проверки устройства на наличие известных читов/аддонов Minecraft Bedrock.

## Обновления в v1.2

- **MD5-based detection**: Система сравнивает MD5 хеши файлов с базой данных `cheats.txt`
- **Comprehensive results**: Приложение показывает ВСЕ найденные читы с полными путями и MD5 хешами
- **Removed ignore feature**: Убрана функция "Игнорировать" - все найденные читы выводятся в полном списке
- **Cheats database**: Все MD5 хеши хранятся в файле `cheats.txt` (один хеш на строку)
- **Git support**: Добавлен .gitignore для правильного исключения файлов при сохранении в репозиторий

## Как это работает

1. При первом запуске приложение создаёт файл `cheats.txt` в папке `filesDir`
2. Сканер вычисляет MD5 хеш каждого найденного файла
3. Сравнивает хеш с базой данных в `cheats.txt`
4. Если хеш найден в базе — файл отмечается как потенциальный чит
5. Приложение выводит ВСЕ результаты с полными путями и MD5 хешами
6. Пользователь может открыть файл для проверки

## Сборка и запуск

1. Откройте проект в Android Studio (Arctic Fox или новее). Убедитесь, что у вас установлен Kotlin 1.9 и Android Gradle Plugin 8.1+
2. Синхронизируйте Gradle.
3. На устройстве (или эмуляторе) предоставьте доступ к файлам: для Android 11+ нажмите кнопку управления доступом к файлам в приложении и включите "All files access" для приложения.

Команды (CLI)

```bash
./gradlew clean assembleDebug
./gradlew installDebug
```

## Примечания
- Утилита сканирования — best-effort (с использованием MD5 хешей и установленных пакетов). Не гарантирует полной идентификации всех читов.
- Приложение НЕ удаляет обнаруженные файлы.
- База `cheats.txt` содержит примеры MD5 хешей и может быть расширена
